🚆 North Central Railway Employee Portal

A **web-based portal** for the **North Central Railway Accounts Department**, providing staff hierarchy, organizational details, duties, and an **admin dashboard** for content management.

---

✨ Features

* 🌐 Public Site– Department info, staff hierarchy, duties, and contacts.
* 🔐 Admin Panel – Update staff data, duties, and frequently used links.
* 👤 Login System – Secure admin access.
* 📱 Responsive Design – Works on desktop & mobile.
* ⚡ Dynamic Data – Staff and duties loaded from backend.

---

 🔗 Deployment

 🌐 Public Portal:https://ncr-accounts-agra.vercel.app/
 ⚙️ Backend API:https://ncr-accounts-agra-backend.onrender.com/

 if you get problem with portal not showing text then please start backend api then reload portal

🚀 Getting Started

✅ Prerequisites

* [Node.js](https://nodejs.org/) (v14+)
* npm (comes with Node.js)
* MongoDB (local or Atlas cloud instance)

 ⚙️ Installation

```bash
# Clone the repository
git clone https://github.com/your-username/ncr-employee-portal.git

# Navigate into the project folder
cd ncr-employee-portal

# Install dependencies
npm install
```

Set up environment variables in `.env`:

```env
PORT=5000
MONGODB_URI=your-mongodb-uri
SESSION_SECRET=your-secret-key
```

---

▶️ Running the Server

```bash
npm start
```

* 🌐 Public site: `http://localhost:PORT/`
* 🔐 Admin panel: `http://localhost:PORT/admin`

---

 📖 Usage

* Visit **Public Site** → View department info, hierarchy, duties, and contacts.
* Use **Admin Panel** → Manage staff details, notices, and links.
* **Login Credentials** → Managed via admin panel (secure login system).

---
 🎨 Customization

* Update **staff & duties** → via Admin Dashboard.
* Add **frequently used website links**.
* Change **logos & images** → `/public/images/`.
